# Canada's Critical Mineral Diplomacy

Published site for the Canada's Critical Mineral Diplomacy research platform.
Live at <https://mineraldiplomacy.github.io>

## What is in this repository

This repository holds only the files the published page needs:

- `index.html` — the platform, generated by an R script (plotly and DT htmlwidgets)
- `lib/` — JavaScript and CSS dependencies written out by the R build
- `mineral_images/` — mineral photographs, with sources listed in
  `mineral_images/mineral_image_sources.csv`
- `.nojekyll` — tells GitHub Pages to serve the files as-is

Everything is static. There is no build step and no server-side code.

## How it is updated

The source data, the R script that generates `index.html`, and the project's
working documents live in a separate private repository. To update the site:

1. Re-run the R script there.
2. Copy the regenerated `index.html`, and any changed files in `lib/` or
   `mineral_images/`, into this repository.
3. Commit and push. GitHub Pages redeploys automatically.

## Notes

- Two videos are embedded from Vimeo, so those need an internet connection.
  Everything else is served from this repository.
- Charts are interactive and need JavaScript.
